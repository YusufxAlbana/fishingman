# Panduan Setup Supabase untuk Game Mancing

Berikut langkah-langkah untuk menghubungkan game ini ke database Supabase agar hasil tangkapan ikan tersimpan secara online.

## 1. Buat Project Supabase
1. Buka [supabase.com](https://supabase.com) dan login/register.
2. Klik **"New Project"**.
3. Pilih Organisasi, beri nama project (misal: `MancingMania`), buat password database, dan pilih region terdekat (misal: Singapore).
4. Klik **"Create new project"** dan tunggu hingga selesai setup.

## 2. Buat Tabel Data (SQL)
Cara paling cepat adalah menggunakan SQL Editor.
1. Di dashboard, pilih menu **SQL Editor** (ikon terminal `>_` di kiri).
2. Paste kode berikut:

```sql
create table catches (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  fish_name text not null
);

-- (Opsional) Matikan RLS agar public/anon bisa insert tanpa ribet setup policy
alter table catches disable row level security;
```

3. Klik **RUN**. Selesai! Tabel `catches` sudah jadi.

## 3. Ambil API Keys
1. Di dashboard, buka menu **Project Settings** (ikon gerigi di kiri bawah).
2. Pilih **"API"**.
3. Di bagian **Project URL**, salin URL-nya (contoh: `https://xyz.supabase.co`).
4. Di bagian **Project API keys**, salin key yang **`anon`** `public`.
